# 心晴 · 情绪日记

一个可安装到 iPhone 主屏幕的私人情绪记录 Web App。

## 功能

- 记录开心、不开心及自定义情绪
- 点击任一主要情绪后，可修改名称和表情；内置与自定义情绪均支持，已有记录会同步更新
- 记录触发事件、身体感受、需要和应对方式
- 区分可观察事实、个人解释与目前证据，减少自动自我归因
- 判断关系事件是需要行动、轻轻询问、观察即可，还是与自己无关
- 记录主动联系、表达在意、轻量邀请及“对方未回应也继续生活”等连接行动
- 修改已经保存的记录
- 根据个人“开心清单”给出自我照顾建议
- 查看历史记录、每周情绪统计与前后两周对比
- 设置每日应用内提醒，并在支持时启用系统通知
- 导出 JSON 或 CSV 备份
- 导入备份时保留原记录并自动跳过重复项
- 生成结构化内容，交给 Codex/ChatGPT 协助复盘

## 隐私

本仓库只保存 App 程序文件。用户填写的情绪记录默认保存在当前设备的浏览器本地存储中，不会随代码上传到 GitHub。

## iPhone 安装

部署为 HTTPS 网页后，用 Safari 打开网址，点击“分享” → “添加到主屏幕”。

> 注意：GitHub 仓库设为私有，并不自动代表 GitHub Pages 网页也是私人访问。启用网页发布前需要单独确认访问范围。
